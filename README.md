# sivateja36.github.io

Portfolio of V. Siva Teja — Full Stack · Azure Cloud · AI/ML Engineer. Live at https://sivateja36.github.io

Plain HTML, CSS and JavaScript, no build tooling required by GitHub Pages.

- `build.py` holds all content (hero, about, experience, projects, skills, contact) and renders `index.html`.
  Edit the data, run `python build.py`, commit `index.html`.
- `assets/css/style.css` — theme tokens (dark default, light via the toggle, persisted in localStorage), layout, animations.
- `assets/js/main.js` — theme toggle, typing headline, reveal-on-scroll, active nav, copy-email.
- `assets/icons/` — Simple Icons brand SVGs inlined by the build. `assets/img/` — portrait, social preview, favicon.
